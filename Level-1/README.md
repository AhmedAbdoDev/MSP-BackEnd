# Level 1 — Backend Development

## Overview

Level 1 is the foundational track of the Backend Development training program. It takes trainees from core client-server and networking concepts to designing, building, securing, documenting, and deploying backend APIs using Node.js and its ecosystem.

Each session pairs conceptual instruction with a practical task and verifiable repository or API evidence, progressing incrementally toward complete backend project milestones.

---

## What You'll Learn

By completing Level 1, trainees will be able to:

- **Backend & Networking Foundations:** Explain the responsibilities of a backend server, trace the full client-server request/response lifecycle, and reason about IP addresses, ports, DNS, TCP/UDP, and HTTP/HTTPS.
- **JavaScript & Node.js Execution:** Apply essential JavaScript patterns for backend logic, work with Node.js core modules and `npm` packages, and reason about synchronous vs. asynchronous execution.
- **RESTful API Engineering:** Build structured REST APIs using Express.js, handle routing, middleware, query/path parameters, request payloads, and standard HTTP status codes.
- **Data Persistence & Modeling:** Integrate MongoDB with Mongoose schemas, models, validation rules, and CRUD database operations.
- **Authentication & Authorization:** Implement user registration and login flows with password hashing, JWT-based authentication, protected routes, and role-based access control.
- **Code Organization & Type Safety:** Structure applications using clean separation of concerns (controllers, services, and models) and apply TypeScript to enforce stronger contracts in backend code.
- **Documentation, Testing & Deployment:** Test APIs systematically with Postman, document endpoints using Swagger / OpenAPI, manage environment variables, and deploy live backend services.

## Learning Approach

Level 1 follows a hands-on, evidence-driven workflow:

1. **Understand the Fundamentals:** Build a clear mental model of how data moves across the network and how server-side applications process requests before relying on abstractions.
2. **Guided Practical Tasks:** Reinforce every session through focused coding exercises and verifiable deliverables (working repositories, commit history, and API tests).
3. **Incremental Project Milestones:** Apply concepts progressively across structured project stages—from in-memory REST routing to persistent database integration, authentication, clean architecture, and live deployment.
