# Backend Training

Welcome to the Backend Training repository.

This repository contains the learning materials and practical work for the Backend training season. It is organized into two levels so members can easily find the content relevant to each stage.


## Training Levels

### Level 1

The first stage of the training. It introduces the core concepts and tools required to start building backend applications.

Sessions will be added under the `Level-1` directory. Each session has its own README describing what the session covers and where to find its materials. Any preparation required before attending will be documented separately under that session's `Prerequisites` directory.

### Level 2

The second stage of the training. Its sessions and materials will be published under `Level-2` when the level get started.

## How to Use This Repository

1. Open the README of the level you are currently following.
2. Open the README of the upcoming session.
3. Check whether that session has prerequisites.
4. Complete the required setup before attending.
5. Use the session materials and complete any tasks published by the training team.

## Notes

- Follow the instructions and software versions specified in each session's prerequisites.
- Check the relevant session folder for updates before each meeting.
- If you face an installation or setup problem, contact the training team before the session and share the error message or a screenshot.
